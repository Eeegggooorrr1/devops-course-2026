# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины

- Гипервизор: Oracle VirtualBox 7.x.
- Операционная система: Ubuntu Server 24.04 LTS.
- Оперативная память: 2048 МБ.
- Количество ядер процессора: 2.
- Диск: 25 ГБ, динамически расширяемый.

## 2. Сетевые интерфейсы

- Адаптер 1: NAT, 10.0.2.15. Используется для доступа в Интернет.
- Адаптер 2: Host-only,  192.168.56.104
  Используется для связи хостовой системы с виртуальной машиной.

## 3. Правило проброса портов

- Протокол: TCP.
- Адрес хостовой системы: 127.0.0.1.
- Порт хостовой системы: 2222.
- Порт гостевой системы: 2222.
- Назначение: доступ к SSH через NAT.

## 4. Учётные записи

- student: исходная учётная запись, использовавшаяся при установке системы.
- devops: отдельная административная учётная запись, включённая в группу sudo.
- Способ входа devops: аутентификация по SSH-ключу Ed25519.
- Открытый ключ пользователя devops хранится в ~/.ssh/authorized_keys.
- На основном компьютере закрытый ключ хранится в ~/.ssh/devops_vm.

## 5. Служба SSH

- Служба: ssh.service.
- Порт: 2222/tcp.
- Файл дополнительных настроек: /etc/ssh/sshd_config.d/99-hardening.conf.
- Резервная копия основной конфигурации: /etc/ssh/sshd_config.backup.
- PermitRootLogin: no.
- PasswordAuthentication: no.
- PubkeyAuthentication: yes.
- PermitEmptyPasswords: no.
- MaxAuthTries: 3.
- LoginGraceTime: 30.
- AllowUsers: devops.
- X11Forwarding: no.
- ClientAliveInterval: 300.
- ClientAliveCountMax: 2.
- Подключение с основного компьютера: команда ssh devops.

## 6. Правила межсетевого экрана

- Средство фильтрации: UFW.
- Политика входящего трафика: deny.
- Политика исходящего трафика: allow.
- TCP/2222: SSH, ограничение частоты подключений (LIMIT).
- TCP/80: HTTP.
- TCP/443: HTTPS.
- Журналирование: medium.

## 7. Снимки состояния

- 01-clean-install - исходная установленная система.
- 02-keys-configured - создан пользователь devops и настроена ключевая аутентификация.
- 03-ssh-hardened - усилена защита SSH.


## 9. Контейнеризация

- Docker Engine установлен из официального apt-репозитория Docker; версия: 29.9.2.
- Плагин Docker Compose: Docker Compose version v5.6.1.
- Учётная запись, входящая в группу docker: devops.
- Каталог проекта на сервере: /home/devops/app.
- Файл переменных окружения: /home/devops/app/.env; владелец devops, права 600. Значения секретов в документацию не включаются.
- Файл конфигурации: /home/devops/app/docker-compose.yml.
- Образ приложения: devops-app:1.0; приложение работает от непривилегированного пользователя app.
- Порт приложения опубликован как 127.0.0.1:5000 -> порт контейнера 5000.
- Порт PostgreSQL 5432 на хосте не опубликован; доступ к СУБД осуществляется через внутреннюю сеть Compose по имени db.
- Именованный том базы данных: app_db_data, точка монтирования в контейнере СУБД: /var/lib/postgresql/data.
- Сеть Compose: backend (имя Docker обычно содержит префикс проекта).
- Конфигурация Nginx: /etc/nginx/sites-available/devops-site; HTTPS location /app/ проксирует запросы на http://127.0.0.1:5000/ и передаёт заголовки Host, X-Real-IP, X-Forwarded-For и X-Forwarded-Proto.
